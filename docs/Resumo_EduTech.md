# 🧩 Resumo Geral – Mini Projeto **EduTech_Consuelo**

Projeto desenvolvido no curso **Full Stack** do **Instituto Consuelo**, em parceria com a **Casa Digital**.  
O sistema simula uma plataforma de **gerenciamento de cursos online**, com ênfase em **SQL (70%)** e **Python (30%)**, aplicando boas práticas de versionamento, modelagem e documentação técnica.

<br>

## 🎯 Objetivo Geral

Criar um sistema de **gerenciamento de cursos online**, integrando banco de dados relacional e scripts Python auxiliares.  
O projeto contempla **cinco etapas principais**, totalizando **20 issues** entre tasks e subtasks, todas vinculadas à macro principal.

## 📁 Estrutura de Diretórios
```md
/docs/ → documentação, diagramas e apresentações
/sql/ → scripts SQL (schema, dados, consultas, relatórios)
/python/ → scripts auxiliares em Python (gerador, validador, utils)
/data/ → arquivos CSV e saídas geradas para testes
```

<br>

## 🧠 Principais Aprendizados

- Normalização e modelagem de banco de dados (1FN, 2FN, 3FN)  
- Criação e execução de scripts SQL com DDL, DML e queries analíticas  
- Automação de geração e validação de dados com Python  
- Integração entre SQL e Python para análise de dados  
- Controle de versionamento e uso do GitHub Project como ferramenta de gestão  
- Boas práticas de documentação e convenções de commits  

<br>

## 🏁 Conclusão

O **Mini Projeto EduTech** representa a aplicação prática dos conhecimentos adquiridos no módulo **Full Stack – Instituto Consuelo + Casa Digital**, consolidando a base técnica em **bancos de dados, automação com Python e versionamento profissional**.  

Todos os artefatos, scripts e relatórios foram desenvolvidos de forma incremental e documentada, garantindo rastreabilidade e clareza no processo de entrega.
